# 高表达且预后好基因的讨论思路 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 高表达且预后差的基因
- 只做 Kaplan-Meier 或差异表达、不讨论机制的请求
- 把反式脂肪酸灌胃实验改写成多吃某类脂肪可以抗癌

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 高表达且预后较好只说明方向，不自动等于抑癌；先写清表型，再选择机制层。
2. 免疫依赖性抑癌要同时看抗原加工、膜表面呈递和 CD8 T 细胞识别，不能只报一个转录变化。
3. 底物与异构体必须分开：有效底物的结果不能外推到结构相近但不走同一通路的对照。
4. 小鼠机制和小型临床队列只能支持假说与验证设计，不能改写成饮食或用药建议。
